# Como resolver problemas de Wi-Fi

1. Desligue o roteador da tomada, aguarde 30 segundos e ligue de novo.
2. No seu dispositivo, selecione a rede Wi-Fi e clique em "Esquecer rede".
3. Conecte novamente digitando a senha.
4. Aproxime-se do roteador para testar o sinal.
5. Teste em outro dispositivo para saber se o problema é só nesse aparelho.

Se continuar sem conexão, abra um chamado informando os dispositivos afetados e qualquer mensagem de erro.
